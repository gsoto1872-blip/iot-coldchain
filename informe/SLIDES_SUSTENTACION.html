1. Resumen Ejecutivo - Alcance de la Implementación

Problema: Las pérdidas por rotura de cadena de frío en farmacéutica y alimentos superan el 15% del valor transportado debido a monitoreos pasivos no integrados.

Alcance Desarrollado:

  • Ingesta Elástica: Cloud Pub/Sub conectado a BigQuery sin código intermedio (*Direct Ingestion*).
  • Arquitectura Medallion: Capas Bronze (crudo particionado), Silver (deduplicado y limpio) y Gold (Star Schema analítico).
  • Procesamiento Híbrido: Hot Path (< 2s para alarmado en vivo) y Cold Path (Batch masivo para cálculo contable de mermas).
  • Capa de Exposición: Microservicio REST API en FastAPI para clientes web, ERPs y Looker Studio.

4. Productos Tecnológicos a Usar (Stack GCP)

  • Google Cloud Pub/Sub: Ingesta asíncrona, desacoplamiento y absorción elástica de ráfagas telemáticas.
  • Google Cloud BigQuery: Motor columnar Lakehouse para almacenamiento particionado por fecha y cómputo SQL distribuido.
  • Google Cloud Storage (GCS): Almacén de objetos para cargas batch de datos maestros de catálogo e inventario.
  • Google Cloud IAM: Seguridad granular con Service Account dedicada y rol de menor privilegio (roles/pubsub.publisher).
  • FastAPI & Python 3.12: Microservicio REST de exposición analítica y orquestador del pipeline ELT.
  • Looker Studio: Conexión nativa a la Capa Gold para tableros ejecutivos y KPIs de control térmico.

5. Dependencias, Supuestos y Fuera de Scope

Dependencias Críticas:

  • Conectividad de red móvil (4G / Cat-M1) en ruta logística.
  • Disponibilidad de servicios en la región GCP us-central1.

Supuestos Clave:

  • Los sensores cumplen con el contrato de datos JSON Schema (UTF-8).
  • El costo unitario del producto se mantiene fijo durante la vigencia del viaje logístico.
  • Cada contenedor refrigerado transporta un lote estándar de 50 unidades.

Fuera de Scope (Out-of-Scope):

  • Diseño físico de circuitos o hardware electrónico de los sensores.
  • Trámites y declaraciones aduaneras internacionales.

9. Conclusiones de la Implementación

  • Factibilidad Técnica Validada: Se demostró la convergencia de streaming no estructurado y catálogos batch en un Data Lakehouse Serverless en GCP.
  • Eficiencia Económica Disruptiva: $0.00 USD en laboratorio y $11.04 USD anuales para 100 vehículos, eliminando la barrera de entrada del costo en la nube.
  • Idempotencia y Calidad: La capa Silver garantiza que reintentos por pérdida de cobertura celular no dupliquen incidentes ni balances de merma.
  • Impacto en Negocio: Convierte la telemetría instrumental en métricas monetarias directas para auditorías sanitarias y liquidación expedita de pólizas de seguros.
